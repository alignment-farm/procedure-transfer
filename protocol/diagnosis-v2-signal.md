# Signal and component follow-ups — diagnostic plan

Specified during the v2 matrix, before inspecting saved-checkpoint probability probes or forward-KL results. The original-rate reverse arm has reached 4/16 recall at both 128 and 256 updates; CE reaches 16/16. This motivates a targeted signal audit rather than another unstructured sweep.

At the base and final four soft-target checkpoints, plus CE-128, measure teacher and student probabilities for the canonical first tool-name token on all 16 diagnostic acquisition inputs. For p=student and q=teacher, independent raw logit derivatives are p_j*(log p_j-log q_j-KL(p||q)) for reverse KL and p_j-q_j for forward KL. These are first-response-position logit gradients, not parameter gradients or whole-answer gradients. On teacher-clear cases (q_correct > .9), count wrong student predictions with p_correct < 1e-4, reverse correct-logit gradient magnitude < 1e-3, and forward magnitude > .5. Such a contrast would exhibit a weak reverse-KL route-correction signal; orientation intervention outcomes are needed for a causal interpretation. Also compare full-sequence teacher scoring with prefix-only scoring to expose numerical or alignment differences.

For component diagnosis, use matched generation with free output versus an oracle-supplied correct routing/syntax prefix, then a correct routing+uppercase-identifier prefix leaving the suffix/closing syntax to generate. These are privileged diagnostic interventions, not memory-free deployed methods. They ask whether eliminating upstream routing errors repairs identifier copying, and whether suffix composition works after both earlier operations are supplied. Hold checkpoint, input and decoding fixed. Use fresh random development identifiers rather than recycling the accepted test set; save construction seed and task identities before model calls. A new transfer claim requires a later separately frozen evaluation.

After the matrix: if forward KL establishes acquisition while reverse KL fails, retain CE-128 and the earliest diagnostic checkpoint reaching at least 15/16 recall per successful soft-target arm for component work; if none reaches that rule, use final checkpoints and report teacher fidelity explicitly. No extra training follows solely to improve a score. A bounded initialization intervention may start reverse KL from an already acquired CE checkpoint to test whether it can preserve a functioning policy; its interpretation must acknowledge that hard-label learning created that policy.
